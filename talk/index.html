Photo-graph-ie

Art of turning photos into graphs.

Short talk

ft. 3 demos.

By Rasagy Sharma.

For IndieWebClub Bangalore's

Special Anniversary Edition Meetup.

May 30, 2026.

“
To photograph is to confer importance.”
– Susan Sontag

Photography is more than merely taking photos.

We capture moments that we want to hold on to.
Context can change what matters: Photos for noticing, remembering, celebrating, archiving, grieving…
Photography becomes journaling, a form of data collection.

I love taking photos.

I hate what social media does with them.

How can we move beyond rigid, templatized formats, & create unique, expressive ways to show data in a set of photos?

How can you make these?

My process

  • Curate photos
  • Extract metadata (Python)
  • Add details to a dataset
  • Explore designs
  • Select the right coding library (P5.js / Mapbox / D3.js…)
  • Host on Github Pages
